# legal

Pagine legali delle mie app, pubblicate con GitHub Pages su `https://justodepp.github.io/legal/`.

## Struttura

Ogni app ha una cartella con il suo nome e, dentro, una cartella per ogni documento:

```
<app>/index.html            presentazione dell'app e link ai documenti
<app>/privacy/index.html    informativa sulla privacy
<app>/terms/index.html      (futuro) termini d'uso
```

Per aggiungere un'app: copia la cartella `spalma/`, cambia i testi e aggiungi la riga nell'`index.html` principale. Gli indirizzi restano stabili e senza estensione, per esempio `https://justodepp.github.io/legal/spalma/privacy/`: sono quelli da incollare in Play Console.
